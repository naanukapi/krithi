# Font sources

BV Nanda Regular, Bold and Italic: supplied project assets originally obtained from https://brahmavidya.co.in. Embedded font copyright: Copyright (c) Summit Information Technologies Pvt. Ltd.

EB Garamond: Google Fonts, https://github.com/google/fonts/tree/main/ofl/ebgaramond. Variable upright and italic files converted from TTF to WOFF2. License included in EBGaramond-OFL.txt.

Alegreya Sans: Google Fonts, https://github.com/google/fonts/tree/main/ofl/alegreyasans. Regular, Medium and Bold files converted from TTF to WOFF2. License included in AlegreyaSans-OFL.txt.

Font formats were converted without changing outlines or glyph content.
